# Hospital Management System 🏥

## Overview
A desktop application designed to help manage hospital information and daily operations.

## Technologies Used
- VB.NET Frontend and Backend
- SQL Server as Database

## Key Features
- Patient record management
- Data entry and record retrieval
- Doctor availability
- Billing
- Appointment Scheduling
- Database integration
  

## Project Purpose
To simplify hospital record management and improve the organization of information.
